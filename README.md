**Desenvolvido integralmente por HRJ_DEV**

### 🇺🇸 English
An elite audio solution for **MushYo** and Roblox games with Boombox support. **BOXFY CLOUD** synchronizes high-quality playlists directly from GitHub, offering a seamless user experience with a minimalist interface and real-time audio management.

* **Cloud Sync:** Playlists updated instantly via GitHub.
* **Smart HUD:** Compact tutorial bar that auto-hides after 30s.
* **Engine:** Full search system and shuffle algorithms.
* **Performance:** Zero-lag execution for high-end and mobile devices.

2. **Equipe** seu rádio (Boombox) dentro do jogo.
3. **Inicie** qualquer música manualmente uma vez para calibrar o sistema.
4. **Aperte [ J ]** para abrir ou fechar o menu principal.
